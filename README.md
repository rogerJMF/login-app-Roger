# Login App - Roger Mendoza

## Descripción

Aplicación web básica de inicio de sesión creada con HTML, CSS y JavaScript.

## Estrategia de ramas

Se utiliza GitHub Flow porque permite trabajar en ramas cortas por funcionalidad y fusionarlas mediante Pull Requests revisados. Esta estrategia facilita la colaboración y mantiene la rama main estable.

## Funcionalidades

- Campo de usuario.
- Campo de contraseña.
- Validación de campos vacíos.
- Mensaje de confirmación o error.
